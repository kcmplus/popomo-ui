启动与部署

安装 Python 3 或 Node.js 18及以上后，Mac 双击 Mac点击启动.command，Windows 双击 Windows点击启动.bat。启动器自动选择空闲端口并打开浏览器，关闭终端或按 Ctrl+C 停止。也可运行 npm start（无需 npm install）。不要直接双击 dist/index.html，模块和数据加载需要本地HTTP服务。若系统限制启动器，可在终端运行 python3 tools/server.py 或 node tools/server.mjs。Windows启动器已静态检查，未在真实Windows环境运行。

静态站点发布根目录设置为 dist；启用 .html 和无扩展名页面解析，正确返回 JS/CSS/SVG/JSON MIME 类型。没有构建步骤。此包未绑定任何托管平台，不含原站点项目ID、仓库历史或密钥。

目录

  • dist：可直接维护的全部 HTML、CSS、JavaScript、图片、字体、模型示例和视频。目录名称虽为dist，其文件本身就是当前项目源文件，不是缺少上游项目的编译产物。
  • docs：完整开发需求、图文教程和历史版本说明。
  • tools：本地HTTP启动器，以及可选教程视频生成脚本。视频已随dist提供，无需重新生成；如需生成，另装Pillow和imageio-ffmpeg，必要时设置POPOMO_FONT_PATH为可用字体路径。
  • SHA256SUMS.json：交付文件摘要，用于核对解压完整性。

导入自己的 Git

在解压目录运行 git init，然后 git add . 与 git commit -m "Import POPOMO V35"，按技术自己的仓库地址设置 remote 后推送。建议初次导入使用私有仓库，完成素材授权确认后再决定是否公开；不要上传真实用户原图、订单、密钥或支付凭据。
